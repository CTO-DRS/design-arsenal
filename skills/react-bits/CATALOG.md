## How to use

**Option A — Registry (recommended, always fresh):**

```bash
# 1. Add registry to components.json in your project root:
#    {"registries": {"@react-bits": "https://reactbits.dev/r/{name}.json"}}
npx shadcn@latest add "@react-bits/SplitText-TS-TW"
```

**Option B — Local copy (offline, this bundle):**

- Tailwind projects → copy from `ts-tailwind/<Category>/<Name>/`
- Plain CSS projects → copy from `ts-default/<Category>/<Name>/`
