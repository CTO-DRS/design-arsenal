# مشيّة 08 — لوحة مبيعات عربية وصولية من الصفر (dataviz · v2.6.0)

**المهمة:** «ابنِ لوحة تحكم مبيعات بالعربية — مؤشرات KPI ورسوم بيانية — أريدها وصولية حقًا وتعمل في الوضع الداكن، وبلا رسوم تُرمّز باللون وحده.»

**الوحدات:** `dataviz` (قيادة) + `tokens` + `rtl-arabic` + `a11y` + `web-vitals` + `verify`.

## الخطوة 1 — اقرأ دليل الوحدة ثم اختر الأنواع من جدول الحسم (dataviz §1/§2)

```bash
# قبل كتابة أول <svg class="chart"> أو استيراد مكتبة: اقرأ الدليل
cat skills/dataviz/MANUAL.md
```

كل رسم جملة واحدة محددة، والشكل يخدم الجملة:

| الجملة | الشكل | القيد الحاكم |
|---|---|---|
| «المبيعات صعدت عبر الأرباع» | خط | ‏4–6 علامات زمنية، ولا يُقص محور الخط دون توثيق |
| «المنطقة الشرقية تتصدر» | أعمدة مرتبة تنازليًا | تبدأ من الصفر — قص القاعدة تضخيم كاذب |
| «توزّع القنوات» | دونات | ≤ 5 شرائح بقيم مكتوبة، والبقية «أخرى» |

## الخطوة 2 — سلاسل الرسوم من ملف الرموز لا من hex (tokens §3 بإشراف dataviz §4/§7)

```css
/* من ملف الرموز — بنظائر داكنة لكل متغير */
.series-1 { fill: var(--chart-1); }  /* أزرق أولًا */
.series-2 { fill: var(--chart-2); }  /* برتقالي ثانيًا — الأبعد إدراكيًا عن الأزرق */
.gridline { stroke: var(--border); } /* شبكة شاحبة خلف البيانات */
```

ثم فاحص الثيمات يطلب النظائر الداكنة — والتباين الرسومي يُفحص في الثيمين معًا (WCAG 1.4.11):

```bash
node skills/dark-mode/scripts/theme.mjs --tokens tokens.light.json --dark tokens.dark.json
node skills/a11y/scripts/contrast.mjs --fg "#2563eb" --bg "#ffffff"   # الفاتح
node skills/a11y/scripts/contrast.mjs --fg "#7aa2f7" --bg "#121212"  # الداكن — أزرق أفتح وأشبع
```

## الخطوة 3 — طبقة الاتجاه العربي (rtl-arabic §1 + dataviz §6)

- الصفحة `dir="rtl"`، وحاوية كل رسم رقمي `dir="ltr"`: المحور الزمني والقيم والـtooltips تبقى منطقية.
- التسميات العربية والشرح خارج الحاوية يرثان RTL — والمواضع بخصائص منطقية (`margin-inline-start`).
- سياسة الأرقام (٠-٩ أم 0-9) قرار واحد من ملف الرموز يُطبق على المحاور والتسميات معًا — لا مزج.
- الأعمدة الأفقية لفئات عربية تنقلب طبيعيًا مع الصفحة — وهذا مرغوب (نص عربي يبدأ من اليمين).

## الخطوة 4 — الترميز المزدوج والإتاحة (dataviz §3 + a11y)

```html
<figure>
  <svg class="chart" viewBox="0 0 320 180" role="img" aria-label="مبيعات الأربع سنوات حسب الربع">
    <title>مبيعات الأربع سنوات — القيم في الجدول المكافئ أدناه</title>
    <!-- سلسلة = لون + شكل، والتسمية المباشرة عند العلامة حيث أمكن -->
  </svg>
  <figcaption>جدول البيانات المكافئ أدناه</figcaption>
</figure>
<table>…</table>  <!-- الجدول المكافئ: الرسم المعقد بلا جدول بديل نصف تسليم -->
```

- لا معلومة باللون وحده: لون + شكل (دائرة/مربع/مثلث) أو تسمية مباشرة عند العلامة.
- الزخرفة (خلفية جزيئات، موجات) `aria-hidden="true"` — والجزيئات canvas نفسها معلّمة كذلك.
- tooltips تفتح بالتركيز لا بالـhover وحده، وكل نص داخل الرسم ≥ 12px مكافئ.

## الخطوة 5 — السوائل والأداء (dataviz §8 بإشراف responsive + web-vitals)

```html
<!-- رسم SVG سائل: viewBox وحده كافٍ — العرض الثابت بالبكسل حظر -->
<svg class="chart" viewBox="0 0 320 180" role="img" aria-label="…">
<!-- مكتبة الرسوم مؤجلة، والرسوم تحت الطية كسولة -->
<script src="https://cdn.example.com/chart.umd.min.js" defer></script>
```

- تحت 480px: بسّط لا صغّر — علامات محور أقل وأعمدة أفقية حيث يلزم.
- حركة دخول الرسم ≤ 500ms داخل حارس `prefers-reduced-motion` (a11y §7).

## الخطوة 6 — بوابة الفاحص الثابتة قبل المتصفح

```bash
node skills/dataviz/scripts/dataviz.mjs src/dashboard.html
# ✓ no dataviz findings      ← مطلوب: صفر HIGH على الأقل قبل المتابعة
```

لو ظهر `CHART-NO-LABEL` أو `CANVAS-NO-TEXT` فهما HIGH: أصلحهما قبل أي جماليات — ثم أعِد الفحص حتى الصفر. وتذكّر أن الفاحص لا يُدين الأيقونات الصغيرة ولا canvas المعلَّم `aria-hidden` — التصنيف للرسوم فقط.

## الخطوة 7 — بوابة التسليم (verify)

```bash
# لقطات: الثيمان × الاتجاهان × 320px، وفيلتر رمادي لمحاكاة عمى الألوان
playwright-cli open src/dashboard.html   # ثم: screenshot لكل حالة
```

قائمة التسليم: كل رسم باسمه ويُعلن، والرسم المعقد بجدول مكافئ، والسلاسل ≥ 3:1 في الثيمين، والرسوم مقروءة بالرمادي، والمحاور ثابتة عند قلب الاتجاه، و320px مبسّط لا مضغوط، والمكتبة لا تهز LCP، و`dataviz.mjs` صفر findings.
