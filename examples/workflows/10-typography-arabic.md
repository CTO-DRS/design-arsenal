# مشيّة 10 — منصة قراءة عربية مشكولة تُطبَع بحِرفة (typography · v2.8.0)

منصة مقالات عربية جاهزة للإطلاق — القالب الأصلي لاتيني، فبقي `letter-spacing` على العناوين، وارتفاع السطر 1.4، واقتباسات بين `"` مستقيمين، وأرقام تتبدل بين ٠١٢ و012 من مقال لآخر. الهدف: طباعة عربية تُقرأ كأنها أُصلت، لا تُرجمت — والتشكيل الكامل في العناوين والاقتباسات يجتاز التكبير 200%.

**الوحدات:** arabic-typography (مالكة الحرف والسطر) · rtl-arabic (الاتجاه والخصائص المنطقية) · i18n (سياسة الأرقام عبر `Intl`) · web-vitals (خط متغير بلا CLS) · a11y (تكبير 200%) · verify (لقطات الثيمين).

---

## 1) الفحص الثابت أولًا — لا تخمين

```bash
node skills/arabic-typography/scripts/typography.mjs src/           # كل الصفحات
node skills/arabic-typography/scripts/typography.mjs src/article.html --json   # للمسار البرمجي
```

الناتج المتوقع لقالب لاتيني مُعرَّب سطحيًا:

- `HIGH LETTERSPACING-AR` — تتبع القالب الأصلي وصل العناوين العربية.
- `HIGH LINEHEIGHT-CLIP` — `body { line-height: 1.4 }` قالبًا؛ و`MED LINEHEIGHT-TIGHT` عند 1.55.
- `MED LATIN-PUNCT-AR` — فواصل لاتينية من لوحة الكتابة في المقدّمات.
- `MED DIGIT-MIX` — مقتطفات تعتمد أرقامًا هندية وجسم الصفحة لاتيني.
- `MED FAKE-ITALIC-AR` / `TEXT-TRANSFORM-AR` — أنماط الاقتباس والتسميات الموروثة.
- `LOW LINEHEIGHT-FIXED` / `AR-QUOTE-ASCII` — سطور بكسل ثابت واقتباسات مستقيمة.

سجّل النتائج قائمة أعمال مرقّمة — كل قاعدة إصلاحها نمطي واحد يُطبَّع على المشروع.

## 2) ارتفاع السطر: القرار الأول

```css
body { line-height: 1.8; }        /* فقرات المقالات المشكولة */
.prose p { line-height: 1.7; }     /* نص واجهة أقصر */
h1, h2 { line-height: 1.25; }      /* العناوين وحدها تُستثنى */
```

- القيم unitless حصراً — أي `line-height: NNNpx` يُستبدل فورًا (يقص عند تكبير 200%).
- القص في البطاقات (`line-clamp`/ارتفاع مقفول) يُختبر بأثقل سطر مشكول قبل اعتماده.

## 3) التوكيد بلا تتبع ولا مائل

```css
/* ✗ ما جاء مع القالب */
[dir="rtl"] .title { letter-spacing: .05em; font-style: italic; }

/* ✓ التكافؤ العربي: تباين وزن داخل عائلة متغيرة */
.title { font-weight: 250; }        /* عنوان ضخم خفيف */
.title b, .kicker { font-weight: 800; letter-spacing: 0; }
:lang(en) .kicker { letter-spacing: .2em; }   /* التتبع للجريات اللاتينية وحدها */
```

عائلة للعناوين (كوفية/هندسية) وأخرى للنص (نسخية) — والإقران يجتاز الجملة المرجعية: تشكيل + رقم + اسم لاتيني + ترقيم بأوزان 400/600/700.

## 4) الأرقام والعلامات: سياسة واحدة

- القرار في ملف إعداد `i18n` (§3): `Intl.NumberFormat` بنظام واحد للمنتج كلها.
- مسح السطور: كل `,` `;` `?` ملصقة بكلمة عربية تصبح ، ؛ ؟ — والاقتباسات «».
- مقتطفات المقالات القديمة تُطبَّع آليًا عند الاستيراد لا يدويًا في كل صفحة.

## 5) الخط المتغير والتبديل

```css
@font-face {
  font-family: "Cairo Var";
  src: url("cairo-arabic-var.woff2") format("woff2-variations");
  font-weight: 200 900;
  font-display: swap;
  unicode-range: U+0600-06FF, U+200C-200E, U+FB50-FDFF;
}
```

- fallback عربي سليم (`"Segoe UI", system-ui, sans-serif`) فلا أربعة أسطر مربعة أثناء التحميل.
- قِس CLS عند التبديل (`webvitals.mjs`) — الارتفاع العربي أعلى؛ احجز المساحة إن لزم.
- الداكن: أرضية الوزن 400 (شراكة `dark-mode`).

## 6) البوابات الأخيرة

```bash
node skills/i18n/scripts/i18n.mjs src/                       # التنسيق عبر Intl حصريًا
node skills/a11y/scripts/contrast.mjs --tokens tokens.json   # الزوجان في الثيمين
node skills/responsive/scripts/responsive.mjs src/           # السوائل بعد رفع الارتفاعات
```

- تكبير 200% على أثقل مقال: لا حرف مقصوص ولا تراكب تشكيل — رقابة WCAG 1.4.4.
- قارئ شاشة: النطق عربي والتشكيل لا يفسد القراءة الآلية (تشكيل المحتوى قرار تحريري موثّق).
